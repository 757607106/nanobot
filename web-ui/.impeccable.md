## Design Context

### Users
- 主要用户为混合角色：运维/SRE、平台管理员、产品/运营、开发者与集成人员都会使用。
- 使用场景以“工作台式控制台”为主：长时间、多任务切换、需要快速定位状态与做配置/排障动作。

### Brand Personality
- 精致科技、可信、克制但不冷漠。
- 核心情绪目标：让用户在复杂系统里保持掌控感与确定性（清晰、稳定、可预期）。

### Aesthetic Direction
- Console 方向：信息密度适中偏高、层级分明、对比清晰、动效用于状态与切换而非装饰。
- 主题策略：默认跟随系统（允许用户覆盖）；亮/暗两套都要“同等质量”，避免暗色只是反相。

### Design Principles
- 一致性优先：视觉语义以 Ant Design Token 为主，CSS 变量只承载全局 surface/brand 级别；避免多套语义并存。
- 可达性默认：所有交互都有键盘路径、焦点可见、语义正确；不把无障碍当“后补”。
- 性能即体验：避免高成本的玻璃化与频繁重绘；动效可降级并尊重 reduced motion。
- 信息架构清晰：导航/页面结构让混合角色能快速定位；减少重复文案与无意义装饰。
